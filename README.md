# وب‌سایت فروشگاه ظروف یکبار مصرف امیر

## امکانات
- کاتالوگ فارسی و راست‌چین، دسته‌بندی و جست‌وجوی محصولات
- قیمت‌گذاری به تومان؛ قیمت خالی به معنی «استعلام قیمت» است
- سبد سفارش و ارسال درخواست از طریق واتساپ
- پنل مدیریت در مسیر `/admin.html` برای ثبت، ویرایش و حذف محصولات
- بارگذاری عکس محصولات در پوشه `images/` مخزن GitHub

## روش مدیریت محصولات
1. سایت را باز کنید و وارد مسیر `https://amir-stor.hostless.site/admin.html` شوید.
2. نام مدیر `amir` است. برای دسترسی نوشتن، یک GitHub Fine-grained Personal Access Token بسازید که فقط به مخزن `golampor939/amir-stor` دسترسی داشته باشد و مجوز Repository contents روی Read and write باشد.
3. کلید را فقط در صفحه مدیریت وارد کنید. کلید در `sessionStorage` همین نشست مرورگر می‌ماند و داخل کد سایت قرار نمی‌گیرد.
4. فرم را پر کنید و عکس محصول را انتخاب کنید؛ عکس در `images/` و اطلاعات در `products.js` ثبت می‌شود. هر ذخیره‌سازی یک Commit در GitHub ایجاد می‌کند و Hostless سایت را از مخزن به‌روزرسانی می‌کند.

## امنیت
- هیچ رمز مدیریتی در کد عمومی قرار داده نشده است.
- دسترسی ویرایش با GitHub token محدود به همین مخزن کنترل می‌شود. کلید را با کسی به اشتراک نگذارید و در دستگاه عمومی از پنل خارج شوید.
- اگر کلید افشا شد، از GitHub آن را فوراً Revoke کنید.

## استقرار
فایل‌های این پوشه را در ریشه مخزن `golampor939/amir-stor` روی شاخه `main` قرار دهید. برای Hostless همان تنظیمات سایت استاتیک فعلی (خروجی `./`) کافی است.
