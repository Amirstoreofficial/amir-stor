# وب‌سایت فروشگاه ظروف یکبار مصرف امیر

## امکانات
- کاتالوگ فارسی و راست‌چین با دسته‌بندی و جست‌وجوی محصولات
- نمایش تصاویر و مشخصات محصولات
- قیمت‌گذاری به تومان؛ قیمت خالی به معنی «استعلام قیمت» است
- سبد سفارش و ارسال درخواست از طریق واتساپ

## مدیریت محصولات
برای افزودن یا ویرایش محصولات، اطلاعات و تصاویر را به مدیر سایت ارسال کنید تا فایل‌های مخزن به‌روزرسانی شوند. این سایت پنل مدیریت عمومی ندارد.

## استقرار
فایل‌های سایت در ریشه مخزن `golampor939/amir-stor` و شاخه `main` قرار دارند. برای میزبانی استاتیک، مسیر خروجی ریشه پروژه (`./`) است.
