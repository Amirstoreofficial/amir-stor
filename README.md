# وب‌سایت فروشگاه ظروف یکبار مصرف امیر

این پروژه یک وب‌سایت استاتیک فارسی، راست‌چین و واکنش‌گرا برای معرفی محصولات و دریافت سفارش از طریق واتساپ است.

## انتشار در GitHub و Hostless
1. یک مخزن جدید و جدا از مخزن `pakino` در GitHub بسازید.
2. فایل‌های این پوشه (`index.html`، `style.css`، `app.js`، `products.js`) را در ریشه مخزن بارگذاری کنید.
3. در Hostless یک Site جدید بسازید و مخزن جدید را متصل کنید.
4. نوع سایت را Static / HTML انتخاب کنید؛ نیازی به دستور Build نیست و مسیر خروجی ریشه `/` است.
5. پس از Deploy، آدرس عمومی سایت را برای مشتریان بفرستید.

## ویرایش محصولات
فایل `products.js` را باز کنید. برای هر محصول:
- `name`: نام محصول
- `category`: دسته‌بندی
- `description`: توضیحات
- `price`: قیمت به تومان؛ برای محصول استعلامی `null`
- `unit`: واحد فروش

نمونه قیمت‌گذاری: `price: 125000`  
برای استعلام قیمت: `price: null`

## ثبت سفارش
سبد خرید، تعداد محصولات را مدیریت می‌کند و متن سفارش را به شماره واتساپ فروشگاه `09152206325` می‌فرستد.

## نکته مهم
این نسخه کاتالوگ و ثبت سفارش واتساپی است. برای پنل مدیریت امن، ذخیره سفارش‌ها در پایگاه داده، مدیریت موجودی و پرداخت آنلاین، باید در مرحله بعد بک‌اند و پایگاه داده متصل شوند. در این نسخه قیمت‌ها و محصولات از فایل `products.js` مدیریت می‌شوند.
