ورود مدیر فروشگاه

این بخش فقط برای مدیر فروشگاه است. نام کاربری مدیر: amir

کلید فقط در حافظه همین نشست مرورگر نگهداری می‌شود و در سایت ذخیره نمی‌شود.

چطور کلید دسترسی بسازم؟
  1. در GitHub وارد Settings شوید.
  2. Developer settings ← Personal access tokens ← Fine-grained tokens را باز کنید.
  3. فقط مخزن amir-stor را انتخاب کنید.
  4. در بخش Repository permissions، گزینه Contents را روی Read and write بگذارید و کلید را بسازید.
  5. کلید را فقط در همین صفحه وارد کنید؛ برای کسی ارسال نکنید.
